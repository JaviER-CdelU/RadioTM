RADIO TIEMPO MUERTO — FIREBASE PARA PUBLICIDADES

La web se puede subir ahora mismo a GitHub Pages aunque Firebase todavía no esté configurado.
La radio, el diseño, las páginas y la instalación PWA funcionan sin Firebase.

Cuando quieras activar el administrador de publicidades:

1. Crear un proyecto nuevo en Firebase.
2. Registrar una aplicación Web.
3. Activar Authentication > Proveedores > Google.
4. Crear Cloud Firestore.
5. Activar Storage.
6. Abrir assets/js/firebase-config.js.
7. Pegar allí el objeto firebaseConfig entregado por Firebase.
8. Cambiar:
   FIREBASE_ENABLED = false
   por:
   FIREBASE_ENABLED = true
9. Publicar las reglas incluidas:
   - firestore.rules
   - storage.rules
10. En Authentication > Settings > Authorized domains agregar:
   - javier-cdelu.github.io
   - el dominio de Vercel cuando exista

QUÉ GUARDA FIREBASE:
- Firestore: título, descripción, enlace, ubicación, orden y estado activa/inactiva.
- Storage: archivo de imagen de la publicidad.

PÁGINA PARA ADMINISTRAR:

IMPORTANTE:
No poner contraseñas privadas ni archivos de cuenta de servicio dentro de GitHub.
La configuración web de Firebase se acompaña con reglas de seguridad y acceso por Google.
