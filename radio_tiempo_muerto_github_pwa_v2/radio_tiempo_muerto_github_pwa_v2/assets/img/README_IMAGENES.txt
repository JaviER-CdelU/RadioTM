CÓMO ORGANIZAR LAS IMÁGENES

- Logo e íconos de instalación: están en esta carpeta.
- Noticias: assets/img/noticias/
- Comunidad: assets/img/comunidad/
- Podcasts: assets/img/podcasts/
- Publicidad: assets/img/publicidad/

Podés pasarle las imágenes a ChatGPT e indicar en qué sección deben aparecer. Se puede devolver un ZIP actualizado.

Cuando los usuarios necesiten subir imágenes directamente desde la página, convendrá usar almacenamiento en la nube (por ejemplo, Firebase Storage) y guardar en la base de datos la URL, el título, la fecha y el estado de aprobación.
