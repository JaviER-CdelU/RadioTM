CAMBIOS DE ESTA VERSIÓN
=======================

1. REPRODUCTOR PERMANENTE
- La radio queda en una barra fija en la parte inferior.
- Noticias, clima, comunidad, podcasts, aportes, contacto y ayuda se abren sin
  recargar el documento completo.
- Por eso la señal sigue sonando al cambiar de sección.
- Los enlaces externos se siguen abriendo normalmente. El Administrador abre
  en otra pestaña para no interrumpir la radio.

2. DATOS OFICIALES DEL RÍO URUGUAY
- assets/data/rio.json guarda el último dato válido.
- scripts/actualizar_rio.py consulta la página oficial de Prefectura Naval.
- .github/workflows/actualizar-rio.yml ejecuta esa consulta aproximadamente
  cada 30 minutos y guarda un cambio solo cuando Prefectura publica un nuevo
  registro.
- Si la fuente falla, no borra el dato anterior.

AL SUBIR A GITHUB
=================
Descomprimir el ZIP y subir TODO su contenido a la raíz del repositorio.
Es importante incluir también la carpeta oculta .github para que funcione la
actualización automática del río.

Después de subir, se puede ir a:
GitHub > Actions > Actualizar datos del río > Run workflow
para hacer una primera prueba manual.
