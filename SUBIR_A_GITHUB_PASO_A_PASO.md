# Archivos que tenés que subir a GitHub

Subí estos archivos y carpetas al directorio principal del repositorio `RadioTM`:

- `pedidos.html`
- `admin-pedidos.html`
- carpeta `css`
  - `pedidos.css`
- carpeta `js`
  - `pedidos.js`
  - `admin-pedidos.js`
  - `firebase-config.js`

## Archivo que tenés que editar

Solo necesitás editar tu `index.html`.

Buscá la zona cercana al reproductor y agregá:

```html
<a href="pedidos.html" class="boton-pedir-tema">
  🎵 Pedir una canción
</a>
```

El archivo `AGREGAR_EN_INDEX.html` contiene el botón y un estilo rápido opcional.

## Qué NO tenés que reemplazar

No reemplaces:

- el reproductor actual;
- el menú;
- las noticias;
- el clima;
- el resto del diseño;
- Firebase que ya uses para otras funciones.

Solo agregamos una nueva página de pedidos y un enlace desde `index.html`.

## Antes de subir

Abrí:

`js/firebase-config.js`

y reemplazá los datos de ejemplo por los datos reales de tu proyecto Firebase.

## Resultado

La nueva dirección será:

`https://javier-cdelu.github.io/RadioTM/pedidos.html`

El panel del operador será:

`https://javier-cdelu.github.io/RadioTM/admin-pedidos.html`
